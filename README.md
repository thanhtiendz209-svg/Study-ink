# Study-ink

Repository được giữ lại theo yêu cầu chủ sở hữu. Mã nguồn ứng dụng, gói ZIP và các workflow xây dựng Study Ink đã được xóa khỏi nhánh `main`.

Hiện không có mã nguồn hoặc chương trình để tải/chạy từ nhánh này. Các bản phát hành và lịch sử commit cũ có thể còn tồn tại trên GitHub cho đến khi được xóa riêng.
